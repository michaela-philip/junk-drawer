This repository contains code for a project on kidney disease. 

### Data Sources
- Chronic Kidney Disease (CKD) data from https://data.cdc.gov/500-Cities-Places/PLACES-County-Data-GIS-Friendly-Format-2020-releas/mssc-ksj7/about_data
- US Census data from IPUMS
- Dialysis facility centers from CMS: https://data.cms.gov/provider-data/dataset/23ew-n7w9
    - currently messy, changed file names manually to make things easy - should go back and script it correctly
- Transplant centers from SRTR: https://www.srtr.org/transplant-centers/?organ=kidney&recipientType=adult&query=
- Transplant centers from UNOS: https://optn.transplant.hrsa.gov/about/search-membership/
- Waitlist Additions from OPTN: https://optn.transplant.hrsa.gov/data/view-data-reports/build-advanced/
